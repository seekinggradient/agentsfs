## Intent
Audit where automatic gardening obtains its prompt and make the canonical codebase prompt authoritative for scheduled jobs.

## Findings and decisions
The hosted cron route contained a separate hardcoded gardening prompt. It read per-workspace AGENTS.md and journal instructions but never loaded prompts/gardening.md. Hub now attaches the exact embedded canonical file to each authenticated maintenance job. Eve preserves it verbatim and adds only a hosted execution adapter for tools, revision handling, existing write/time limits, and unsupported operations. A missing prompt fails the job rather than using a stale substitute. Per-repo content cannot replace the canonical policy.

## Progress
Added byte-for-byte dispatch coverage, adapter preservation tests, and missing-prompt rejection tests. Updated hosted architecture documentation. Typecheck and targeted cron tests passed; full Hub/hosted tests and the production build are running.
